Wasmer CDN starter

Every file in public/ is served from the site root, for example /image1.avif. Wasmer Edge CDN Cache is enabled in app.yaml.

Check the cache

Request a file twice and read the x-cache-status header:

curl -s -o /dev/null -D - https://cdn-wasmer-starter.wasmer.app/image1.avif | grep -i x-cache-status

The first request is a MISS, and the next one from the same Edge node is a HIT. Use a GET request as above: a HEAD request (curl -I) does not fill the cache. Read the CDN Cache documentation.
